Subroutines
setup_jules

Module for storing constants for the UKCA box model that are stored in the Jules model for the operational runs. To reduce the number of dependencies on Jules, we store the constants here in the box model and set them to the same values as in Jules.

Note the values of each constant are dependent on the number of land types (ntype), which is a configuration option set by the user. setup_jules() must therefore be called.
