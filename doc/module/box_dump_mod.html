Write every value passed into, or returned from, the UKCA library to a plain-text dump file, one value per line, so that two box models can be compared with diff.

Each line is fully keyed and self-contained:

<step> <section> <name> <index> <value>

e.g.

0 ukca_setup:in i_ukca_chem - 51
3 ukca_step:out tracers (1,1,1,2) 9.90333269774813254E-008 3E7A9C...

so dumps can also be compared after sort if the two models make calls in a different order. A real value is written twice: with 17 significant digits, which round-trips a double exactly, and as the 16 hex digits of its bits. The hex makes the comparison bit-for-bit without relying on how the compiler converts reals to decimal, and shows how many bits differ.

This module only depends on Fortran intrinsics and ereport_mod (which both the old and new box models have), so the same file can be compiled into the old (UM/FCM) box model unchanged.

Usage:

call dump_open("ukca_dump.txt")
call dump_section("ukca_setup:in", 0)
call dump("i_ukca_chem", i_ukca_chem)
call dump("tracers", tracer_ukca)
call dump_close()

All dump calls are no-ops while no dump file is open. Instead of calling dump_open directly, a driver (or wrapper) can call dump_open_from_env, which opens the file named by the environment variable UKCA_DUMP_FILE, if set, so dumping can be switched on without changing driver code.

Optional arguments that are not present, and allocatable arguments that are not allocated, are recorded with dump_marker as "" and "" so that differences in what is passed are also visible.


Uses

    • iso_fortran_env
    • ereport_mod

Open the dump file named by the environment variable UKCA_DUMP_FILE, if it is set and non-empty. Only the first call has any effect, so it is cheap to call at the start of every wrapped API routine.
