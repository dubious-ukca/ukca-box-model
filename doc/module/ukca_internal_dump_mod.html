dump_ukca_internal_config

GENERATED FILE - DO NOT EDIT. Generated by tools/gen_ukca_internal_dump.py from UKCA apps2.2/um13.9 (4a2baa5). Regenerate after any UKCA upgrade.

Dumps the internal UKCA config and state with box_dump_mod, read directly from UKCA. It never calls ukca_setup, ukca_set_environment or ukca_step. A driver adds:

if (ukca_dump_on()) call dump_ukca_internal_config() after ukca_setup and photol_setup if (ukca_dump_on()) call dump_ukca_step_in() immediately before ukca_step if (ukca_dump_on()) call dump_ukca_step_out(tracers, ntp) immediately after ukca_step

See tools/gen_ukca_internal_dump.py for what is dumped.
