Module for reading, validating and printing the box model configuration. Box model configurations are read from a user-provided namelist file and are stored in a box_config_type type, which is used to control the behaviour of the box model and UKCA.


Uses

    • umprintmgr
    • ereport_mod
    • ukca_api_mod
