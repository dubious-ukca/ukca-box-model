Name Type Default Description
fastjx_mode integer None

fast-jx photolysis mode above cutoff (1=lookup tables, 2=fast-jx + lookup tables, 3=fast-jx)
fastjx_numwl integer None

number of wavelengths to use in fast-jx. Options are 8, 12 or 18
i_photol_scheme integer None

Photolysis scheme: 0 = off, 1 = stratospheric only, 2 = offline/2-D, 3 = Fast-JX
i_solcylc_type integer None

apply solar variability to photolysis (fast-jx only). 0 = no solar cycle, 1 = observed cycle, 2 = average cycle.
solcylc_start_year integer None

1st year for the solar cycle (used when i_solcylc_type = 1)
l_cloud_pc2 logical None

True if the atmosphere model is using the PC2 cloud scheme
l_strat_chem logical None

True if UKCA is using a scheme that involves stratospheric chemistry i.e. Std Strat, Strattrop or CRI-strat
l_use_photolysis logical None

True if UKCA is expecting to apply Photolysis rates in the solver and hence needs the rates from the parent
fastjx_prescutoff real None

Cut-off Pressure for tabulated photolysis
l_offline_photol logical None

True to read photolysis rates from offline_photol_rates_file, rather than calculating them online
