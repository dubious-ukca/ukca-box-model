public subroutine read_box_config(filename, cfg)

Uses

    • box_debug_mod
    • ukca_missing_data_mod
    • box_err_codes_mod

Reads the box model configuration from a user-provided namelist file and stores the configuration in a box_config_type type.

Arguments

Type IntentOptional Attributes Name
character(len=*), intent(in) :: filename

Name of the namelist file to read
type(box_config_type), intent(out) :: cfg

The resulting box model configuration read from the namelist file
