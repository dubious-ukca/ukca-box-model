public subroutine box_time_initialise(time_step_nml, model_duration_nml, start_year, start_month, start_day, start_hour, start_minute, start_second, l_360)

Initialize the time manager with the time step, model duration and the model start date and time from the configuration namelist. Current time and step are set to 0.
